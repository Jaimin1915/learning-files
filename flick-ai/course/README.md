# Flick Mastery Course: Images, Video, Camera, 3D

My step-by-step course to learn everything Flick can do, from a good image prompt to a "The Duel"-level action scene. Built from Flick's official docs plus the techniques from top creators' public workflows.

**How every lesson works**
1. **Learn:** read the lesson (10 minutes).
2. **Do:** the exercise, with cheap draft models first.
3. **Check:** the review checklist. Judge, don't guess.
4. **Save:** copy the prompt that worked into [Prompt Library](prompt-library.md).

**Golden rules (apply to everything)**
- References carry the look; the prompt describes **only the change**.
- One shot = one job. One clip = one main action + one camera instruction.
- Write what can be **seen or heard**, never just a mood word ("cinematic", "sad").
- Change **one thing** per try, so you know what fixed it.
- Draft cheap, finish expensive. Check the Run cost every time.

## The roadmap (about 8 weeks at ~1 hour a day)

### Level 1: Image mastery (week 1–2)
| # | Lesson | You'll be able to |
|---|---|---|
| 1.1 | [Prompt anatomy](L1-01-image-prompt-anatomy.md) | Write a prompt that gives the image you pictured |
| 1.2 | Shot sizes, angles and lenses | Name and get any framing: ECU → EWS, low/high/OTS/POV, 24mm vs 85mm |
| 1.3 | Lighting and focus | Control light source, direction, shadows, depth of field |
| 1.4 | Styles | Pick, create and save a style; photoreal vs 2D |
| 1.5 | Characters | Turnaround sheets, expression sheets, Character Reference |
| 1.6 | Locations | A location handbook + environment references |
| 1.7 | Editing images | Edit, inpaint, remove background, color & light, combine, upscale |
| 1.8 | Camera Control | New angles of the same shot for reverse and reaction shots |

### Level 2: Video basics (week 3)
| 2.1 | Frame to Video and the 3-sentence prompt |
| 2.2 | Subject motion vs camera motion · the 3-take exercise |
| 2.3 | Duration, resolution, start and end frames |
| 2.4 | Continuing shots: Extend Video, Extract Frame, Trim on canvas |

### Level 3: Camera movement (week 3–4)
| 3.1 | The 10 camera moves (push, pull, pan, tilt, track, orbit, crane, dolly zoom, handheld, static) and when each one means something |
| 3.2 | Writing camera moves models actually follow |
| 3.3 | When words fail: show the move with a reference video |

### Level 4: Performance, voice and dialogue (week 4)
| 4.1 | Directing acting with visible behavior (Seedance Performance Guide) |
| 4.2 | Voices that stay consistent · Character Dialogue and lip sync |

### Level 5: Omni Reference (week 5)
| 5.1 | Giving every reference one job: identity, location, motion, camera, audio |
| 5.2 | Motion Reference and Edit Video |

### Level 6: 3D Stage (week 5–6)
| 6.1 | Convert an image to 3D · Figure vs Human |
| 6.2 | Cameras: lens, Path, Follow, Transform keyframes, presets |
| 6.3 | Animating people: clips, paths, Play Mode, Rig Transform |
| 6.4 | Record → render first frame → Omni Reference → final clip |

### Level 7: Action and choreography (week 6–7)
| 7.1 | The 5 stages of every hit: preparation → attack → contact → reaction → recovery |
| 7.2 | Weapon paths, time windows, multi-opponent staging |
| 7.3 | Breaking down "The Duel": a 13-shot timed fight prompt |

### Level 8: Sound, edit and finish (week 7–8)
| 8.1 | Sound effects, ambience, music |
| 8.2 | Editing for story, keyframes, motion titles, color |
| 8.3 | Export for YouTube, Shorts, Reels |

### Level 9: Capstone film (week 8)
A 1–2 minute film using everything, following Flick Academy's 10 steps. Suggested story: **Arjuna vs Karna** or **Hanuman's leap**.
