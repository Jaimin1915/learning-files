# Lesson 8: The Video Editor

Sources: [Timeline basics](https://flick.art/docs/timeline-basics) · [Add and reorder clips](https://flick.art/docs/add-and-reorder-clips) · [Trim and split](https://flick.art/docs/trim-and-split) · [Clip properties](https://flick.art/docs/clip-properties) · [Keyframes](https://flick.art/docs/keyframes)

Everything in the editor costs **0 credits**.

## Layout
- **VIDEO EDITOR** tab at the top (or the Video Editor button on the canvas toolbar).
- Left: **Assets** (tabs: Assets, Effects, Transitions, Motions, SFX) · Middle: preview · Right: **Properties** · Bottom: timeline.
- Empty timeline offers **Let Agent build my timeline**.

## Tracks: use the MAIN track
- Picture clips belong on **Main**. The **magnet** (closes gaps automatically) **only works on Main**.
- Clips on other "Video" tracks + later length changes = overlaps and black gaps.
- Check the first clip starts at **0:00**.
- A black frame with a spinning circle in preview = still **loading**, not a gap.

## Adding and ordering
- Assets panel → **+ (Add to timeline)** on each shot, in story order. Each scene has a still and a video in Assets: pick the right one.
- Reorder with Select tool (`V`) by dragging.

## Trim, split, speed
| Action | How |
|---|---|
| Trim | Drag a clip's edge (frames are hidden, not deleted, so you can drag back) |
| Split at playhead | `S` |
| Razor tool | `C` |
| Delete left / right of playhead | `Q` / `W` |
| Speed | Properties → Playback → Speed (0.1x–32x). 0.5x doubles a 5s clip to 10s |
| Reverse | Properties → Reverse (free) |

## Sound
- **Mute AI clip sound** when using narration: Shift+click all video clips → Properties → Sound → Volume **0%** (multi-select edits all at once).
- Narration on the audio track starting at 0:00. **Edit picture to the voice**: the voice decides how long each scene lasts.
- Volume and Fade in/out in Properties → Sound.

## Keyframes = free camera moves
1. Select clip, playhead at start, Properties → **Scale** → click the ◆ diamond.
2. Move playhead to the end, type a new value (e.g. 130). Flick adds the second key.
3. Slow **zoom-in** on a still = movement for 0 credits. **Pull-out** = start at 110%, end at 100%.
Keyframable: Position, Scale, Rotation, Opacity, Crop, Volume.

## Free editing tricks
- **Reuse shots** to match words: the army shot zoomed in = "what Arjuna sees"; the 2 AM boy again when the farmer "worries every night".
- **Cut, don't animate** risky actions (before → after).
- Hold a moment after the key line (1–1.5s) to let it land.
- Fade to black at the end.

## Shortcuts
Space = play · Home = start · ←/→ = 1 frame (Shift = 5) · ↑/↓ = previous/next cut · `N` = snapping · `T` = add text
