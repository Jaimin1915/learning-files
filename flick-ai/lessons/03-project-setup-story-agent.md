# Lesson 3: Project Setup, Story, Memory and the Agent

Sources: [Create Your First Project](https://flick.art/docs/create-your-first-project) · [Story basics](https://flick.art/docs/script-view-basics) · [Talking to the agent](https://flick.art/docs/talking-to-the-agent) · [Navigation](https://flick.art/docs/navigation) · [Sections and folders](https://flick.art/docs/sections-and-folders)

## 1. Create the project
1. Projects home page → **No style** opens **Explore Styles** (1,000+ styles).
   - Or **Create My Style → Upload Style Reference** (up to 5 images showing the look).
2. Pick the aspect ratio next to it.
3. Click **Blank canvas** (typing in the big prompt box makes the agent start creating, which can spend credits).
4. Rename the project.

Inside the project the **Visual style** sits at the top of the chat panel.

## 2. Keep ONE project per film
Everything (characters, scenes, clips, voice) in one project so you can reference it all with `@` and edit it in one timeline.

## 3. Story tab: your script lives here
- Top tabs: **Story · Canvas · 3D Stage · Video Editor**
- Paste your script with **Ctrl+V** (keeps formatting).
- Don't use the Script box's **Upload** for notes-style scripts. It expects screenplay format (INT./EXT., character cues).

## 4. Project memory: write rules once
Chat header → **Agent memory → For this project → Add a memory**. The agent reads it on **every** message.
Put in it: style recipe, exact character descriptions, rules ("no text in images", "always ask before generating"). Keep it short (there's a length limit).

## 5. The agent's approval mode (protect credits!)
Next to the 🎤 mic in the chat box:
| Mode | Asks before |
|---|---|
| Autopilot | Only deleting |
| **Auto** (default) | Generating video |
| **Manual** ✅ | **Anything that costs credits**, and shows the price |

## 6. Talking to the agent well
- **Select the node first.** Its thumbnail appears above the chat input: that's what the agent looks at.
- Mention things by name with `@`. Name your sections and nodes.
- Change **one** thing at a time. Say what must **stay**.
- Tell each reference its **role**: "Use Frame X ONLY for the chariot and background, not for the pose."
- The agent can edit the timeline for free: move, trim, speed, volume, fades.

## 7. Organizing the canvas
- **Sections** group nodes. Select nodes → **Create section**, or press `S` and draw.
- **Lock section** (🔒 beside the name) stops new generations landing inside it.
- One section per scene + one locked **Characters** section.
- **Assets** (left toolbar) lists every media node, with **Archived** filter.

## 8. Navigation shortcuts
| Action | How |
|---|---|
| Pan | Right-click drag, middle mouse, or Hand mode |
| Zoom | Ctrl/⌘ + scroll, pinch |
| Fit whole canvas | ⌘1 |
| Add text note / section | `T` / `S` |
| Run selected nodes | Enter (⚠️ costs credits) |
| Delete | Backspace |
| Tidy canvas | Left toolbar button (⌘Z undoes) |
| Lost a node? | ⌘1 or click the minimap |
