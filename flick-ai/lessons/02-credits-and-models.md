# Lesson 2: Credits and Choosing a Model

Sources: [How credits work](https://flick.art/docs/how-credits-work) · [Model Credit Costs](https://flick.art/docs/model-credit-cost) · [Choosing a model](https://flick.art/docs/choosing-a-model)

## Free credits (every account, including Free)
| Credits | Amount | When | Expires |
|---|---|---|---|
| Signup bonus | 100 | Once | Never |
| Weekly | 100 | Every **Monday 00:01 UTC** | Next Monday (no carry-over) |
| Discord reward | 200 | Once, at flick.art/claim-discord | Never |

- Credits that expire soonest are spent first.
- Hover your balance (top right) for the breakdown. Click it for **Usage details** (every charge).
- Top-ups (one-time packs) are only for Standard, Pro, Studio plans.

## When are credits refunded?
- Credits are **held** when a generation starts.
- **Failed** (error, time-out, flagged) → refunded automatically.
- **Finished** but you don't like it → **still charged**.
- ⚠️ **Deleting a node does NOT stop the generation.** It keeps running and you're charged. Video can take several minutes, so wait and watch the node status (pending → processing → done). (I lost 20 credits learning this.)

## Real costs I used
| Generation | Credits |
|---|---|
| GPT Image 2.5: low / medium / high | 2 / 5 / 10 |
| Nano Banana Pro 1K | 30 |
| Video: Auto or MiniMax H3 Fast, 720p, 5s | 20 |
| Voice: Eleven v4, one run (even a long 2-min narration) | 8 |
| Veo 3.1 video, 8s, with audio | 640 |

What makes cost go up: **model**, **duration**, **resolution**, **audio** (Kling and Veo charge extra for audio), **batch count**.

## Picking a model
1. Start from the task: node menu → **Image**, **Video** or **Audio** → an action.
2. The **Model** dropdown shows each model's credit range.
   - 🔒 lock = needs a higher plan
   - greyed out = temporarily unavailable
3. **Video:** try **Auto** first (picks a model for speed and value).
4. Read each model's description: max length, audio, start/end frames, resolutions.
5. **Draft, then finish:** test with a cheap draft model, use the best model only for the final take.
6. **Compare fairly:** same reference, same prompt, same duration.
7. Use **one model per scene** for consistent characters.
8. A model flagged your request? Fix the prompt. Switching models is not a way around moderation.

**Free plan video models:** Auto, MiniMax H3 Fast, MiniMax H3 Max, Pruna Draft.

## My budget strategy (Free plan)
- **Images first (5 each), video second (20 each).** Approve every still before animating.
- One video clip per scene; fill the rest with **stills + slow zoom** in the editor (0 credits).
- Plan around the **+100 every Monday**.
- One full lesson film (~8 stills + 3 videos + voice) ≈ **80–100 credits = one week**.
