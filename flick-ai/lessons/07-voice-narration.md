# Lesson 7: Voice and Narration

Sources: [Text to Voice](https://flick.art/docs/text-to-voice) · [Voice Consistency](https://flick.art/docs/voice-consistency) · [Import audio](https://flick.art/docs/import-audio)

## Generate a voice
1. **+ → Generate Voice** (or select a character image → **Audio → Generate Voice**).
2. Model: **Eleven v4** (or v3). Up to 10 speakers with **+ Add Speaker**.
3. Click the voice dropdown → **hover to preview** (free) → **Use**.
4. Type the lines. Bracket cues direct the delivery: `[whispers]`, `[softly]`, `[slowly]`, `[laughs]`, `[sighs]`, `[dramatic pause]`.
5. Check the cost on Run.

## Big money-saver: the whole narration in ONE run
- One run cost **8 credits** even for a 2.5-minute narration.
- 12 separate runs (one per scene) would be ~96 credits.
- One run also means **one consistent voice** for the whole film.
- After pasting long text, **check the Run cost again** before clicking.

## Writing for a voice
- Short sentences; punctuation where you want pauses.
- Write numbers as words ("two a.m.", not "2 a.m.").
- Spell non-English words phonetically so an English voice pronounces them: *Karmanye vaadhikaaraste, maa phaleshu kadaachana*.
- For a narrator, remove extra speakers (one voice reads everything, even quoted lines).
- An Indian voice (e.g. **Harish, Professional, Indian**) pronounces Indian names naturally.

⚠️ `[dramatic pause]` only made ~0.5s pauses (same as a sentence break). Add longer pauses in the editor if needed.

## Check the result
- [ ] No dropped or repeated words
- [ ] Bracket words were not spoken out loud
- [ ] Pauses fall where the punctuation is
- [ ] Delivery fits (whisper isn't shouted)

## Keep the voice consistent
Reuse the **same voice selection** for every new line of that character. An old audio file still contains the old words, so generate new lines with the same voice.
