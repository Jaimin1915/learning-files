# Lesson 9: My Full Workflow and Mistakes to Avoid

What I actually did to make the Gita 2.47 film, start to finish.

## The workflow (in order)
| # | Step | Credits |
|---|---|---|
| 1 | Plan: goal, 4-line brief, ratio, 3 success checks ([Lesson 1](01-before-you-generate.md)) | 0 |
| 2 | One project · custom style from my own frames · Blank canvas | 0 |
| 3 | Approval mode **Manual** · script in **Story** · rules in **Project memory** | 0 |
| 4 | Extract frames → 3 **character sheets** → lock in **Characters** section | 15 |
| 5 | **Establishing shot** first, then every scene still, each checked | ~45 |
| 6 | Turn approved stills into **video**: gentle shots first, risky ones one at a time | 20 each |
| 7 | **Narration** in one Eleven v4 run | 8 |
| 8 | **Edit** to the voice: order, trim, speed, mute, zooms, text | 0 |
| 9 | Export → YouTube version + Shorts/Reels + thumbnail | 0 |

## Mistakes I made (and the fix)
| Mistake | What happened | Fix |
|---|---|---|
| Deleted a video node that was "taking too long" | It kept running; charged twice (lost 20) | Wait; watch node status; only retry if **failed** |
| Started video from the toolbar **+** | Empty node, Run greyed out | Start from the image: **Video → Generate Video** |
| Clips on a "Video" track, not Main | Magnet didn't work, black gap appeared | Put all picture clips on **Main** |
| Spent almost all credits on video | Couldn't generate captions | Images first, video only for key scenes; plan around Monday's +100 |
| Didn't check the last second of a clip | Arjuna's bun vanished at the end | Always watch to the last frame; trim the bad part |

## Habits that worked
- Check **every** result against a written checklist before moving on.
- Never regenerate first. Name the problem, then try the cheapest fix (trim, edit, re-cut).
- Name and lock sections. Rename nodes.
- Keep the Run cost in mind every single time.
- Judge shots **in sequence**, not alone.
