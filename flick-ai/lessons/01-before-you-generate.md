# Lesson 1: Before You Generate

Source: [flick.art/docs/before-you-generate](https://flick.art/docs/before-you-generate)

**Big idea:** every generation costs credits and AI results vary each time. Five minutes of planning before clicking **Run** saves credits and gives better results.

## 1. Start small: one scene, not a whole movie
- You don't need a finished screenplay. Pick **one moment**.
- Have a story? Pick the moment where something **changes**.
- Have only a feeling or look? Pick a small event that expresses it.
- Ask: **"What should the viewer understand or feel after this scene?"**

## 2. Write a one-line goal
Formula: **who + where + what happens**
> A traveler notices a forgotten red umbrella at a quiet station after rain.

❌ One clip that shows 3 locations, a complex action and the ending.
✅ Split the idea into separate shots, with one idea per shot.

## 3. Write a 4-line scene brief
| Question | Example |
|---|---|
| What happens? | Traveler sees the umbrella and leaves it where its owner can find it |
| What changes? | An ignored object becomes noticed |
| What should the viewer feel? | A small sense of care, not big drama |
| What to avoid? | Scary storm, complicated action |

Keep it visible (a **Text node**: press `T` on the canvas) and judge every result against it.

## 4. Choose the aspect ratio first
On the projects home page, the button next to **No style** sets the ratio:

| Ratio | Use for |
|---|---|
| 16:9 | YouTube / widescreen |
| 9:16 | Reels, Shorts, TikTok |
| 1:1 | Square post |
| 21:9 | Wide cinema look |
| 4:3 · 3:4 · 5:4 | Classic / retro |

- New generations use the **last ratio you chose**.
- Some models follow the source image's shape. Check the panel's ratio before **Run**.
- Changing ratio later crops the image. If you need both 16:9 and 9:16, leave space around the subject.

## 5. Use references with a purpose
- Each reference should do **one job**: who the character is, what the place looks like, or the style.
- **Generate Image** takes up to **10 reference images**, but treats them all the same way.
- To keep the **same person** across shots, use **Character Reference** (see [Lesson 4](04-character-sheets.md)).
- A style reference does **not** keep a face the same.
- Two references disagree (costume, lighting)? Decide which one wins before generating.
- Use only material you own or have permission to use.

## 6. Choose a model for the task
- First decide the task: **make an image**, **edit an image**, or **make video**.
- No model is best at everything. Keep a note of what worked.
- See [Lesson 2](02-credits-and-models.md).

## 7. Check the cost before Run
- The number on the **Run** button is the credit cost.
- It changes with batch size (**1x**), resolution, video length, audio.
- **Golden rule:** fix the cheap **still image** first, then make the expensive **video**.

## 8. Decide what "success" means
Write 2–3 checks before the first test, for example:
- Are the traveler and the umbrella easy to tell apart?
- Does the station look like the same place in every shot?
- Can the viewer understand what the traveler noticed?

When something fails: **name the problem first, then change only ONE thing**, and compare.

## 9. Canvas comfort
Gear icon **Canvas settings** on the left toolbar:
- **Appearance:** Follow system / Light / Dark
- **Lines between nodes:** All / Selected / Off
- **Minimap**, and **Mouse & trackpad → Scroll to zoom**

These only change your view, never the generated pixels.

## ✅ Checklist before every new project
- [ ] One-line goal (who + where + what happens)
- [ ] 4-line brief
- [ ] Aspect ratio chosen
- [ ] References chosen, one job each
- [ ] 3 success checks written
